# 自动审查与修复

用于 Codex 中的代码、文档和方案审查，支持 goal 模式的持续自动开发。核实实际缺陷后做最小修复，按证据复查和收敛，避免误改既定设计、过度设计及反复修改。

## 触发与使用

```text
$pi_review_quality_guardrails 审查当前改动
$pi_review_quality_guardrails 验收本阶段的登录功能及相关文档
$pi_review_quality_guardrails 只审查这份方案，不修改
```

在 goal 开始时可指定：

```text
本目标使用 $pi_review_quality_guardrails 管理审查修复。
每个可验证工作单元完成后局部评审，整体目标完成前独立验收。
```

技能允许按任务描述自动选用；它不是后台监听器或强制执行的 CI 门禁，自动匹配不保证每次触发。显式指定一次有助于明确本目标采用的流程。

## 两种模式

- **局部评审**：日常默认。检查选定改动及必要上下文；修复后复查直接影响，可复用独立审查者和仍有效的验证证据。
- **验收评审**：完整覆盖约定阶段或目标，修复后使用新独立上下文完整复查。完整范围不自动等于整个项目。

已授权开发中的审查沿用修改授权；显式调用默认审查并修复。明确只读时仅报告核实后的发现，不修改审查对象。问题、可选建议和验证限制分开说明，不承诺绝对无缺陷。

## 执行条件与边界

需要能够读取目标内容及必要上下文。代码验证使用项目实际具备的构建、测试或运行工具；文档验证不机械要求代码测试。

独立审查需要宿主支持并允许委派。工具不可用时披露限制并完成可做的检查，自查不能冒充独立验收通过。不强制不同型号的模型，不要求安装其他技能或创建 AGENTS.md。

不因调用本技能自动获得提交、推送或发布授权。goal 跨轮恢复保留范围、设计依据、发现处置和验证证据；预算耗尽或关键证据受阻不代表目标完成。
