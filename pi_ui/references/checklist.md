# 界面验收清单

仅选择与本次界面自定义新增或修改及其影响有关的项目；存在模板不免除审查。不适用项可省略；清单不要求新增状态、动画、功能或测试设施。具体数值沿用项目规范，不统一规定字号、控件高度或像素误差。

## 模板与新设计差异

- 有模板但新设计不同的，先明确差异涉及的布局、控件、尺寸、样式、图标或交互；按新设计检查差异部分，并检查对相邻区域的影响。
- 明确要求的设计差异不是缺陷，不以恢复旧模板为默认修复方案；其余沿用部分仍按模板检查，避免意外偏离。

## 完整性与图标

- 按需求核对控件、标签、文字、图标及提示，没有遗漏；不擅自增加装饰。
- 需要图标时检查实际可见性、资源、大小、位置及图文间距。留意透明、与背景同色、裁切、遮挡及缩放导致的消失。
- 图标和文字在相关状态下仍能正确表达含义；资源已加载不代表显示正确。

## 风格、文字和对齐

- 同用途、同层级控件的字体、字重、颜色、尺寸等级、边框及效果符合依据；不同用途可以合理不同。
- 检查文字内容、内边距、行高及换行；不出现非预期截断、重叠或异常留白。
- 明确应对齐的是左右边界、中心线、文字基线还是表单列；分别检查外框与内部图文，外框齐平不代表内容对齐。
- 图标存在固有留白时，结合实际视觉和项目既有做法判断；不凭个人偏好反复进行无依据的微小偏移。

## 布局与内容变化

- 检查间距、排列、相邻区域的挤压、位移、裁切及遮挡；不能仅查看新控件本身。
- 文字或布局变化时检查有代表性的长文本、中文或项目支持的本地化内容，以及相关窗口尺寸。
- 字体、图标或缩放逻辑变化时检查相关显示缩放；不强制每次覆盖所有 DPI。
- 允许有依据的固定尺寸与定位；检查是否与布局管理冲突，不用零散偏移掩盖根因。

## 操作与状态

- 验证需求及已有控件支持的相关默认、禁用、焦点、选中、加载或错误状态，不为了清单新增这些状态。
- 新增或变更操作区时，检查相关点击、键盘操作、Tab 顺序及焦点反馈。
- 原生按下反馈、焦点绘制，以及设计允许的展开、重排、换行不属于缺陷；非预期跳动或内容消失需要处理。

## 按实际技术栈选择

| 技术栈 | 必要时检查 |
| --- | --- |
| Qt Widgets | 布局边距与间距、sizeHint/sizePolicy、字体度量、QStyle/QSS 覆盖及高 DPI 图标 |
| Qt Quick/QML | 实际采用的 Layouts/anchors、隐式尺寸、文字布局及控件样式，不套用 Widgets 专属规则 |
| MFC/Win32 | 对话框资源与字体、DLU/像素转换、动态或手动布局、自绘状态、图像列表及 DPI 处理 |
| Web | 组件变体、布局与计算样式、字体加载、相关响应式尺寸及状态 |

只应用项目实际使用的机制。浏览器工具不能替代原生窗口验证；自绘控件的自动化属性可能不完整，应结合实际显示检查。
